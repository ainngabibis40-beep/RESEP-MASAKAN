# 🍳 DapurKreatif - Ide Masakan & Cemilan Ringan

**DapurKreatif** adalah aplikasi web interaktif sederhana dan modern yang menyajikan berbagai ide masakan harian, camilan praktis, serta minuman segar. Didesain secara responsif untuk pengguna HP maupun Desktop.

---

## 🌟 Fitur Utama

- **🔍 Cari & Filter Cepat**: Filter berdasarkan kategori (*Cemilan Gurih, Cemilan Manis, Makanan Utama, Minuman Segar*) atau cari berdasarkan nama bahan baku.
- **🎲 Acak Resep**: Fitur tombol acak untuk membantumumu saat bingung menentukan menu masakan hari ini.
- **🔖 Bookmark / Favorit**: Simpan resep favoritmu di memori browser (*localStorage*).
- **➕ Tambah Resep Sendiri**: Masukkan resep kreasi milikmu langsung dari form aplikasi web.
- **🌙 Mode Gelap / Terang (Dark Mode)**: Tampilan visual yang nyaman di mata kapan saja.

---

## 🚀 Cara Menjalankan Secara Lokal

1. Download atau *clone* repositori ini.
2. Buka file `index.html` menggunakan browser pilihanmu (Chrome, Firefox, Edge, Safari).
3. Selesai! Tidak memerlukan *server* atau *setup dependencies* tambahan.

---

## 🌐 Cara Deploy ke GitHub Pages

1. Upload seluruh file (`index.html` & `README.md`) ke repositori GitHub kamu.
2. Masuk ke tab **Settings** di repositori GitHub tersebut.
3. Di menu sebelah kiri, klik **Pages**.
4. Pada bagian **Build and deployment** -> **Branch**, pilih `main` (atau `master`) dan folder `/ (root)`.
5. Klik **Save**. Tunggu beberapa saat, dan web kamu akan aktif secara publik!
