# 🍳 DapurKreatif - Ide Masakan & Cemilan Rumahan

Aplikasi web interaktif dan responsif untuk mencari ide masakan cepat saji dan cemilan ringan menggunakan bahan-bahan yang tersedia di kulkas rumah.

## ✨ Fitur Utama
1. **Desain Menarik**: UI modern dengan Tailwind CSS.
2. **Katalog Resep**: Kumpulan ide cemilan ringan yang mudah dibuat.
3. **Acak Resep**: Fitur randomizer untuk merekomendasikan resep buat kamu yang bingung.

## 🚀 Cara Menjalankan di Local
1. Ekstrak file `DapurKreatif_Web.zip` ini.
2. Buka berkas `index.html` di peramban favoritmu (Chrome/Firefox/Edge). Tidak perlu server lokal, cukup double-click file HTML-nya!

## 🌐 Cara Deploy ke GitHub Pages
1. Buat repositori baru di GitHub (misal: `dapur-kreatif`).
2. Upload berkas `index.html` dan `README.md` hasil ekstraksi ini ke repositori tersebut.
3. Masuk ke tab **Settings** -> **Pages** pada repositori GitHub-mu.
4. Pada bagian **Build and deployment**, pilih branch `main` (atau `master`) dan folder `/ (root)`.
5. Klik **Save**. Situs web kamu akan aktif dan bisa diakses oleh siapa saja!
