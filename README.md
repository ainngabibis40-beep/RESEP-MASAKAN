# 🍳 CemilanKu - Ide Masakan & Cemilan Ringan

CemilanKu adalah aplikasi web sederhana berbasis HTML, CSS, dan JavaScript murni yang berisi kumpulan ide dan resep cemilan ringan yang mudah dibuat di rumah.

## ✨ Fitur
- **Tampilan Menarik (Responsive):** Desain UI yang modern dan cocok diakses dari HP maupun Desktop.
- **Pencarian Cepat:** Fitur *live search* untuk mencari resep berdasarkan nama atau bahan.
- **Pop-up Resep (Modal):** Menampilkan detail bahan-bahan dan cara membuat tanpa perlu pindah halaman.

## 🛠️ Teknologi yang Digunakan
- HTML5
- CSS3 (Flexbox & CSS Grid)
- Vanilla JavaScript (ES6)

## 🚀 Cara Menjalankan secara Lokal
1. Download atau *clone* repository ini.
2. Pastikan ketiga file (`index.html`, `style.css`, dan `script.js`) berada di dalam folder yang sama.
3. Buka file `index.html` menggunakan browser (Chrome, Firefox, Safari, dll).

## 🌐 Cara Hosting Gratis di GitHub Pages
1. Buat repository baru di GitHub Anda.
2. Upload file `index.html`, `style.css`, `script.js`, dan `README.md` ini ke repository tersebut.
3. Buka menu **Settings** di repository GitHub Anda.
4. Pada menu sebelah kiri, cari bagian **Pages**.
5. Di bagian *Source*, ubah dari `None` menjadi `main` (atau `master`), lalu klik **Save**.
6. Tunggu beberapa menit, lalu refresh halaman tersebut. Anda akan mendapatkan *link* web Anda yang sudah live!
