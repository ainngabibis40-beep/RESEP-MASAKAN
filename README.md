# 🍳 Dapur Ceria - Ide Masakan & Cemilan Ringan

**Dapur Ceria** adalah aplikasi web responsif dan interaktif yang menyediakan berbagai ide resep masakan rumahan, cemilan ringan, dan minuman segar. Dibuat dengan HTML, CSS, dan JavaScript murni (*Vanilla JS*).

![Preview Dapur Ceria](https://images.unsplash.com/photo-1498837167922-ddd27525d352?auto=format&fit=crop&w=800&q=80)

## 🚀 Fitur Utama

- **Pencarian Real-Time**: Cari resep berdasarkan nama atau bahan-bahan secara langsung.
- **Filter Kategori**: Saring resep berdasarkan jenis (*Cemilan Ringan*, *Masakan Utama*, *Minuman Segar*).
- **Penemu Resep Acak (*Randomizer*)**: Fitur khusus untuk membantu pengguna yang bingung memilih menu hari ini.
- **Modal Detail Resep**: Menampilkan bahan-bahan lengkap dan langkah-langkah pembuatan secara terstruktur.
- **Desain Responsif**: Nyaman diakses melalui perangkat Android/iOS maupun Desktop.

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman web.
- **CSS3**: Layouting (Flexbox & Grid), styling, animasi modal, dan desain responsif.
- **JavaScript (ES6)**: Manipulasi DOM, pencarian, filter, dan logika sistem modal.
- **FontAwesome**: Ikon antarmuka.
